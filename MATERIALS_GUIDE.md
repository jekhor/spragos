# Инструкция для LLM: генерация заданий для тренажёра литовской грамматики

Этот документ — самодостаточное задание для языковой модели. Передайте его целиком и в конце допишите запрос, например: «Сделай новую тему: склонение существительных 1-го склонения (-as, -is, -ys)». Шаблон запроса — в конце документа.

Каждая тема состоит из двух файлов: заданий `data/<имя>.txt` (§2–§6) и грамматической справки `data/<имя>.md` (§7).

---

## 1. Что такое тренажёр

Веб-тренажёр показывает литовские предложения и короткие связные тексты с пропусками. Над текстом выводится «банк слов», и ученик перетаскивает слова в пропуски. Тренируется грамматическая форма: падеж, число, род, время. Лексику тренажёр не проверяет.

Ученики — русскоязычные взрослые уровня A1–B1. Интерфейс на русском, задания на литовском.

Одна тема — один текстовый файл `data/<имя>.txt` в UTF-8. Твоя задача — написать содержимое такого файла.

## 2. Формат файла

Пример:

```
# Формы сверены с …  /  ЧЕРНОВИК: требует проверки
@title: Daiktavardžiai (I linksniuotė) — существительные на -as, -is, -ys
@group: Склонение
@description: Мужской род, единственное и множественное число, все падежи
@hints: always
@distractors: namas, namo, namui, namą, namu, name

# --- Единственное число ---
Mano brolis gyvena {Kaune|Kaunas}.
Šiandien neturiu {laiko|laikas}.
Važiuoju į darbą {autobusu|autobusas}.

--- Mano kambarys
Mano kambarys nedidelis, bet jaukus.
Prie {lango|langas} stovi stalas, o ant {stalo|stalas} — kompiuteris.
---
```

### Правила синтаксиса

Парсер строгий. Нарушение правила даёт ошибку, и строка пропускается.

1. **Одна строка — одно предложение-задание.** В каждом предложении должен быть хотя бы один пропуск. Пустые строки допустимы и игнорируются.
2. **Комментарий** — это строка, которая начинается с `#`. Комментариев в конце строки с текстом не бывает.
3. **Заголовок** состоит из строк вида `@ключ: значение`. Допустимы только эти ключи:

   | Ключ | Обязателен | Смысл |
   |---|---|---|
   | `@title:` | да | Название темы. Формат: «Литовский термин — русское пояснение» |
   | `@group:` | да | Раздел меню, например `Склонение`, `Спряжение`, `Предлоги` |
   | `@description:` | да | Одна строка по-русски: что именно тренируется |
   | `@hints: always` | см. §4.2 | Всегда показывать подсказки под пропусками |
   | `@reference:` | нет | Путь к справке `.md` относительно `data/`, если она называется не так, как тема (§7) |
   | `@distractors:` | нет | Общий запас неправильных форм через запятую |
   | `@subtopic:` | нет | Начало подтемы, см. п. 7 ниже |
   | `@word-practice: off` | нет | Не предлагать тренировку одного слова: для тем, где слов много и каждое встречается несколько раз (существительные) |

4. **Связный текст** начинается строкой `--- Заголовок по-литовски` и заканчивается строкой `---`.
   - Каждая строка внутри становится абзацем, весь текст — одно задание.
   - Строки внутри текста могут быть без пропусков, но во всём тексте пропуски нужны.
   - Строк вида `---` вне этой роли быть не должно. Реплики диалога начинай с длинного тире `—`, а не с дефисов.
5. **Пропуск** записывается в фигурных скобках: `{ответ|подсказка|лишние, формы}`.

   ```
   {namą}                        только правильный ответ
   {namą|namas}                  ответ + подсказка (начальная форма, показывается мелко под пропуском)
   {namą|namas|namo, namui}      + свои неправильные варианты для банка слов
   {šį/tą|šis}                   несколько правильных ответов через «/»; в банк попадает первый
   {į mokyklą|mokykla}           в ответе можно несколько слов (например, предлог + существительное)
   {namą||namo, namui}           неправильные варианты без подсказки
   ```

   - Внутри пропуска не бывает других фигурных скобок, и частей не больше трёх.
   - Буквальную фигурную скобку в тексте пиши как `\{` и `\}` (на практике это не нужно).
6. **Регистр.** Если пропуск стоит в начале предложения, ответ пиши с заглавной: `{Jam|jis} patinka…`. Подсказку пиши со строчной.
7. **Подтемы.** Тему можно разбить на части строками `@subtopic: Заголовок | пояснение` (пояснение — необязательные примеры слов). Подтема включает все задания ниже, до следующей `@subtopic`; задания до первой подтемы — ошибка. Ученик может выбрать тему целиком или отдельные подтемы. Если подтемы — типы склонения или спряжения, начинай заголовок с номера: `@subtopic: 1. мужской род, -(i)as, -is, -ys | namas, kelias`. Для существительных по этому номеру тест определяет тип склонения (файл темы должен быть в `NOUN_FILES` в `tests/forms.test.mjs`).

## 3. Как работает банк слов (это влияет на подсказки)

Ученик выбирает один из двух режимов банка:

- **«Только ответы»** — в банке перемешаны правильные ответы всех пропусков раунда.
- **«+ лишние формы»** — к каждому пропуску добавляются 1–2 неправильные формы. Их источники в порядке приоритета:
  1. явные из третьей части пропуска (`{…|…|a, b}`);
  2. **правильные ответы других пропусков этой же темы с той же подсказкой.** Для `{namą|namas}` возьмутся `namo`, `name`, `namu` из других предложений, где подсказка тоже `namas`;
  3. список `@distractors`.

Отсюда следствия:

- **Подсказки пиши строго единообразно**, по правилам §4.2. Тогда тренажёр сам подберёт хорошие неправильные формы того же слова.
- **Повторяй одни и те же леммы в разных падежах.** Лучше 6 предложений с `namas` в шести падежах, чем 6 разных существительных по одному разу.
- Явные неправильные формы (третья часть) нужны, только если у леммы в файле мало других форм или нужна конкретная типичная ошибка, например `dvi` вместо `du`.
- `@distractors` заполняй 6–12 частыми формами темы на случай, если других источников не хватит.

## 4. Требования к содержанию

### 4.1. Однозначность — самое важное

Ученик должен однозначно определить правильный ответ по предложению. Иначе он поставит грамматически верную форму, а тренажёр засчитает ошибку.

- **Контекст должен определять, какое слово нужно**, а не только форму. Плохо: «Aš {jį} matau» — подходят и jį, и ją, и juos. Хорошо: «Tai mano brolis. Aš {jį|jis} matau kiekvieną dieną».
- Если по смыслу годятся два варианта, перечисли оба через `/`: `{šiame/tame|šis} name`.
- Учитывай, что в банке лежат ответы на *другие* предложения раунда. Не делай пропуск, куда так же хорошо встаёт форма из соседнего предложения.
- Падеж должен определяться управлением в самом предложении: предлогом, глаголом, отрицанием (родительный при «ne-»), количеством, временем.
- **Число тоже должно быть видно из контекста.** «Paskambinau {draugui|draugas}» допускает и draugams. Дай опору: согласованное прилагательное или местоимение (*senam draugui*, *šiems keliams*), числительное, *daug*, *keli*, *visi*, *abu*. Если опоры нет, укажи обе формы через `/`.

### 4.2. Подсказка-лемма

Подсказку (вторую часть пропуска) пиши по этим правилам:

- **Существительное** — им. п. ед. ч.; для pluralia tantum — им. п. мн. ч.: `{namą|namas}`, `{marškinius|marškiniai}`.
- **Прилагательное** — им. п. ед. ч. мужского рода: `{gražią|gražus}`.
- **Личное местоимение** — им. п. нужного лица и числа. Для «они» (ж. р.) — `jos`, для возвратного — `savęs`: `{jas|jos}`, `{save|savęs}`.
- **Местоимения, которые склоняются как прилагательные** (šis, tas, anas, kitas, kuris, koks, toks, joks, pats, visas, kiekvienas) — им. п. ед. ч. **мужского** рода, даже если ответ женского рода или во множественном числе: `{šiai|šis}`, `{kurią|kuris}`. Род и число ученик должен вывести из существительного. Эти слова собраны в одной теме (`kuris-koks.txt`), не дублируйте их в других.
- **Количественное и собирательное числительное** — им. п. **мужского** рода, даже если ответ женского рода: `{dvi|du}`, `{keturias|keturi}`, `{dvejas|dveji}`. Род ученик выводит из существительного.
- **Порядковое числительное** — им. п. ед. ч. м. р.: `{aštuntą|aštuntas}`.
- **Глагол** — инфинитив: `{skaitė|skaityti}`.
- **Предлог + существительное** — существительное в им. п., предлог входит в ответ: `{į mokyklą|mokykla}`.

Если в теме без подсказки нельзя понять, *какое* слово нужно, ставь в заголовке `@hints: always`. Это касается прилагательных («žaliame / dideliame parke»), числительных (какое число), глаголов (какой глагол). Для местоимений обычно хватает контекста, `@hints: always` там не нужен.

### 4.3. Тривиальные пропуски

Пропуск, где ответ совпадает с подсказкой (`{du|du}`, `{Ji|ji}`, `{Šis|šis} filmas`), полезен в небольшом количестве: ученик учится замечать, что здесь нужен именительный падеж (или что форма совпадает с начальной) и ничего менять не надо. Пусть таких будет 2–3 на слово, но не больше 10% пропусков темы — тест проверяет эту долю.

### 4.4. Охват и баланс

- Покрой **все падежи** (кроме звательного, если тема не про него) и оба числа, а для изменяемых по родам слов — оба рода. Перед тем как писать, мысленно составь таблицу «падеж × число × род» и распредели предложения по ней примерно поровну.
- Используй разные типы управления: предлоги (be, iki, nuo, prie, su, apie, į, pas, per, už…), глаголы с родительным (laukti, bijoti, ieškoti, trūkti), с дательным (patikti, padėti, skambinti, duoti), с творительным (domėtis, didžiuotis, pasitikėti), отрицание, количество.
- Чередуй позицию пропуска: начало, середина и конец предложения.
- В предложении 1–2 пропуска, не больше. В связном тексте — 1–2 пропуска на строку.

### 4.5. Язык

- Только естественные современные литовские предложения, какие могли бы стоять в учебнике A1–B1: быт, семья, город, учёба, работа, еда, путешествия, погода.
- Длина предложения — 4–12 слов. Лексика базовая, без редких слов и архаизмов.
- Используй литовские имена и реалии: Ona, Jonas, Tomas, Vilnius, Kaunas, Neris, cepelinai…
- Пиши правильными литовскими буквами: ą č ę ė į š ų ū ž. Никакой латиницы без диакритик.
- Перевод не нужен: тренажёр его не показывает.
- Всё, что вне пропусков, тоже должно быть грамматически верным. Проверяй согласование во всём предложении.

### 4.6. Объём

- **Новая тема:** 25–40 отдельных предложений и 2–3 связных текста по 4–6 строк.
- **Пополнение существующей темы:** столько, сколько попросили. Не повторяй уже существующие предложения и не меняй заголовок файла.
- Группируй предложения комментариями-разделами: `# --- Единственное число ---`, `# --- Предлог su + творительный ---`.

## 5. Проверка — обязательно

Ошибка в учебном материале хуже, чем его отсутствие: ученик выучит неправильную форму.

1. **Сверь каждую форму в ответах** с таблицей склонения или спряжения. Если тебе доступны учебники, используй их. У пользователя они лежат в `/home/jek/work/Lithuanian/*.pdf`, текст извлекается командой `pdftotext -layout файл.pdf -`. Хорошие источники:
   - `2014_Žingsnis_I.pdf` — в приложении таблицы местоимений и числительных;
   - `petrasiuniene_e_langas_i_lietuviu_kalba.pdf` и `2014_Žingsnis_I.pdf`, `2014_Žingsnis_II.pdf` — местоимения, существительные, прилагательные, причастия;
   - `Complete_Lithuanian.pdf`, `Press_I_J__Ramoniene_M_-_Colloquial_Lithuanian_-_2011.pdf` — таблицы с английскими пояснениями;
   - `2015_365_lietuvių_kalbos_veiksmažodžiai_rusų_kalba.pdf` — спряжение глаголов.

   **Не используй материалы Šaunuolė** (файлы `Saunuole-*.pdf`, сайт saunuole.lt): ни таблицы, ни примеры, ни структуру объяснений.
2. **Сверь управление:** какой падеж требует предлог или глагол.
3. **Прочитай каждое предложение целиком** с подставленным ответом. Оно должно быть верным и естественным.
4. **Проверь однозначность** (§4.1): не подходит ли в пропуск другая форма из банка.
5. **Первые строки файла — комментарий о статусе проверки:**
   - если сверял с источниками: `# Формы сверены с <источники>.` и `# Предложения составлены автоматически — по возможности покажите их носителю.`;
   - если сверить было не с чем: `# ЧЕРНОВИК: сгенерировано автоматически, требует проверки.`
6. Если у тебя есть доступ к репозиторию, положи файл в `data/` и запусти `node --test`. Тесты проверят:
   - синтаксис;
   - что каждый ответ — существующая форма своей подсказки. Это работает для местоимений, числительных, прилагательных и существительных: их парадигмы описаны в `tests/paradigms.mjs`. Тип склонения существительного тест берёт из номера в начале заголовка подтемы;
   - число тривиальных пропусков и повторы предложений.

   Если тема новая (например, глаголы), добавь её парадигмы в `tests/paradigms.mjs`, сверив их с учебниками.

Если в какой-то форме ты не уверен, не включай её. Лучше на одно предложение меньше.

## 7. Грамматическая справка (`data/<имя>.md`)

Справка открывается во всплывающем окне прямо во время упражнения. Это **шпаргалка, а не учебник**: таблицы форм и несколько коротких правил, которые нужны, чтобы решить задания темы.

**Формат** — Markdown с ограниченным набором разметки. Другая разметка не поддерживается: ссылки, картинки, HTML и вложенные списки покажутся как обычный текст.
- Первая строка — `# Заголовок`, такой же, как `@title` темы.
- Разделы — `##` и `###`.
- Таблицы: `| … | … |` со строкой-разделителем `|---|---|`.
- Списки `-` и `1.`, врезки `> …`.
- Выделение: `**жирный**`, `*курсив*`, `` `код` ``.

**Содержание:**
- Полные таблицы форм для всего, что тренируется в теме: все падежи × число × род. Первая колонка — падеж с русским сокращением: `Vard. (им.)`, `Kilm. (род.)`, `Naud. (дат.)`, `Gal. (вин.)`, `Įnag. (твор.)`, `Viet. (местн.)`; в первой таблице можно добавить вопрос: `Vard. (им., kas?)`.
- Если в таблице и единственное, и множественное число строками, раздели их строками-заголовками `| **ед. ч.** | | … |` и `| **мн. ч.** | | … |`.
- Для слов, которые склоняются по типам (существительные), вторая колонка — `Окончание`: только окончания этого типа (`-o, -io`), дальше примеры слов.
- Окончания выделяй жирным, основу — нет: `ger**as**`, `graž**iam**`. Неправильные формы (местоимения, du/dvi) выделять не нужно.
- После каждой таблицы — строка «Так же: …» с 4–8 словами того же типа из заданий темы.
- Исключения — во врезке `> …`.
- В конце раздел `## Что запомнить`: 3–6 пунктов про управление (предлоги, глаголы, отрицание) с короткими примерами из заданий темы.
- Пояснения — по-русски, примеры — по-литовски с переводом в скобках или после тире.
- Объём — примерно экран-два. Широкие таблицы на телефоне прокручиваются, но больше 5–6 колонок лучше не делать.

**Проверка:** каждая форма в таблицах сверяется с учебниками точно так же, как ответы заданий (§5). Справка с ошибкой вреднее, чем задание с ошибкой.

Если справка общая для нескольких тем, назови её отдельно (например, `daiktavardziai.md`) и укажи в заголовке каждой темы `@reference: daiktavardziai.md`.

## 8. Формат ответа

- Предложи имя файла: строчная латиница без диакритик, литовский термин темы, например `daiktavardziai-1.txt`, `veiksmazodziai-butasis-laikas.txt`.
- Выдай содержимое обоих файлов — `.txt` и `.md` — отдельными блоками кода.
- После блока — коротко по-русски:
  - что покрыто (таблица «падеж × число» с количеством пропусков);
  - с чем сверялся;
  - какие формы или предложения вызывают сомнение.

## 9. Идеи тем и особенности

| Тема | Особенности |
|---|---|
| Существительные по склонениям | Уже есть: `daiktavardziai.txt`, пять подтем по типам склонения. Новые задания добавляй в нужную подтему. Подсказка — им. п. ед. ч. |
| Предлоги и падежи | Ответ — предлог вместе с формой (ответ `prie namo`, подсказка `namas`) или только форма после предлога, который уже стоит в тексте |
| Прилагательные: степени сравнения | Подсказка — положительная степень. `@hints: always` |
| Местоименные (определённые) прилагательные (didysis, gražioji) | `@hints: always` |
| Настоящее, прошедшее, будущее время | Подсказка — инфинитив. Время должно следовать из обстоятельства (vakar, rytoj, dabar). `@hints: always` |
| Прошедшее многократное (-davo) | Маркеры: anksčiau, kai buvau vaikas, kiekvieną vasarą |
| Возвратные глаголы (-si, приставочные -si-) | Подсказка — инфинитив (`praustis`) |
| Повелительное наклонение | Подсказка — инфинитив, адресат из контекста (tu / jūs / mes) |
| Причастия | Сначала уточни у пользователя, какие именно |
