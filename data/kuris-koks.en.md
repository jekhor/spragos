# Other pronouns

This topic covers pronouns (*įvardžiai*) other than personal ones:
- **demonstrative** — šis, tas, anas, toks;
- **interrogative and relative** — kuris, koks;
- **determinative** — pats, visas, kiekvienas, kitas;
- **negative** — joks.

All of them change for gender, number and case and agree with the noun like adjectives:

| Word | Meaning | Kind |
|---|---|---|
| kuris, kuri | which, who (of known ones) | interrogative and relative |
| koks, kokia | what kind of | interrogative |
| toks, tokia | such | demonstrative |
| joks, jokia | no, none | negative |
| šis, ši | this | demonstrative |
| tas, ta | that | demonstrative |
| anas, ana | that (over there) | demonstrative |
| kitas, kita | other | determinative |
| pats, pati | -self; the same | determinative |
| visas, visa | all, whole | determinative |
| kiekvienas, kiekviena | every, each | determinative |

## Kuris, kuri

Declines like *jis / ji*: kur**iuo** like j**uo**, kur**iuos** like j**uos**.

| Case | masc. | fem. | masc. pl. | fem. pl. |
|---|---|---|---|---|
| Vardininkas (nom., kas?) | kuris | kuri | kurie | kurios |
| Kilmininkas (gen., ko?) | kurio | kurios | kurių | kurių |
| Naudininkas (dat., kam?) | kuriam | kuriai | kuriems | kurioms |
| Galininkas (acc., ką?) | kurį | kurią | kuriuos | kurias |
| Įnagininkas (instr., kuo?) | kuriuo | kuria | kuriais | kuriomis |
| Vietininkas (loc., kur?) | kuriame | kurioje | kuriuose | kuriose |

**In a relative clause** (*namas, kuriame gyvenu* — “the house I live in”):
- *kuris* takes its **gender and number** from the word it refers to: *namas* → kuris, *knyga* → kuri, *vaikai* → kurie;
- its **case** depends on its role in the relative clause, i.e. on the verb or preposition.

| Example | Why this case |
|---|---|
| Tai knyga, **kurią** skaitau. | skaityti ką? — accusative |
| Tai draugas, **kurio** seniai nemačiau. | negation — genitive |
| Mergina, su **kuria** kalbėjau, — mano sesuo. | su + instrumental |
| Namas, **kuriame** gyvenu, labai senas. | where? — locative |
| Vaikai, **kuriems** patinka sportas, lanko baseiną. | patikti kam? — dative |

> A relative clause with *kuris* is always preceded by a comma. If it is in the middle of the sentence, a comma follows it too.

## Kuris or koks?

- **kuris** — “which” of several known ones: *Kurią knygą imsi — šitą ar aną?*
- **koks** — “what kind of”, a question about quality: *Kokią knygą skaitai? — Įdomią.*

In questions both often fit: *Kuriame / Kokiame name gyveni?*

## Koks, toks, joks

These three decline the same way. Almost all forms are like the adjective *žalias* (kok**io**, kok**iam**, kok**ią**…). Only three forms differ: nominative singular **koks**, masculine accusative singular **kokį**, masculine nominative plural **kokie**.

| Case | masc. | fem. | masc. pl. | fem. pl. |
|---|---|---|---|---|
| Vard. (nom.) | koks | kokia | kokie | kokios |
| Kilm. (gen.) | kokio | kokios | kokių | kokių |
| Naud. (dat.) | kokiam | kokiai | kokiems | kokioms |
| Gal. (acc.) | kokį | kokią | kokius | kokias |
| Įnag. (instr.) | kokiu | kokia | kokiais | kokiomis |
| Viet. (loc.) | kokiame | kokioje | kokiuose | kokiose |

- **toks** — such: Niekada nemačiau **tokio** gražaus ežero.
- **joks** — no, none; almost always with negation, so usually in the genitive: Neturiu **jokio** noro. Nėra **jokių** problemų.

## Pats, pati

| Case | masc. | fem. | masc. pl. | fem. pl. |
|---|---|---|---|---|
| Vard. (nom.) | pats | pati | **patys** | pačios |
| Kilm. (gen.) | **paties** | pačios | pačių | pačių |
| Naud. (dat.) | pačiam | pačiai | **patiems** | pačioms |
| Gal. (acc.) | **patį** | pačią | pačius | pačias |
| Įnag. (instr.) | pačiu | pačia | pačiais | pačiomis |
| Viet. (loc.) | pačiame | pačioje | pačiuose | pačiose |

The forms in bold are the ones most often confused.

- **pats / pati** — “-self”: Aš **pati** pasiuvau suknelę. Kalbėjau su **pačiu** direktoriumi.
- **tas pats / ta pati** — “the same”, both parts decline: Gyvename **tame pačiame** name. Važiavome **tuo pačiu** autobusu.
- **toks pats / tokia pati** — “the same kind of”: Turiu **tokius pačius** batus kaip tu.
- **pačiame / pačioje** + place or time — “in the very…”: **pačiame** centre, **pačioje** pradžioje.

## Šis, tas, anas, kitas

- **šis** — “this”, something near;
- **tas** — “that”;
- **anas** — “that one over there”: usually contrasted with *šis* (*šis namas, o anas…*) or used in set phrases: *anoje pusėje* (on the other side), *anais laikais* (in the old days), *aną dieną* (the other day), *anuo metu* (at that time).

*Tas* and *anas* decline the same way; *šis* almost the same, but with -i- in the stem. *Kitas* declines like an ordinary adjective in -as (*geras*): **kitu**, **kiti**, **kitus** — not “kituo”, “kitie”, “kituos”, as its similarity to *tas* might suggest.

### Masculine

| Case | šis | tas | anas | kitas |
|---|---|---|---|---|
| **singular** | | | | |
| Vard. (nom.) | šis | tas | anas | kitas |
| Kilm. (gen.) | šio | to | ano | kito |
| Naud. (dat.) | šiam | tam | anam | kitam |
| Gal. (acc.) | šį | tą | aną | kitą |
| Įnag. (instr.) | šiuo | tuo | anuo | **kitu** |
| Viet. (loc.) | šiame | tame | aname | kitame |
| **plural** | | | | |
| Vard. (nom.) | šie | tie | anie | **kiti** |
| Kilm. (gen.) | šių | tų | anų | kitų |
| Naud. (dat.) | šiems | tiems | aniems | kitiems |
| Gal. (acc.) | šiuos | tuos | anuos | **kitus** |

| Kilm. (gen.) | šios | tos | anos | kitos |

| Įnag. (instr.) | šia | ta | ana | kita |

| **plural** | | | | |
| Vard. (nom.) | šios | tos | anos | kitos |
| Kilm. (gen.) | šių | tų | anų | kitų |
| Naud. (dat.) | šioms | toms | anoms | kitoms |
| Gal. (acc.) | šias | tas | anas | kitas |
| Įnag. (instr.) | šiomis | tomis | anomis | kitomis |

> Watch out for homonyms: **tai** is both the dative of *ta* (*tai moteriai* — “to that woman”) and the particle “this/it” (*Tai mano namas*). **Tas** is both the masculine nominative and the feminine accusative plural (*tas knygas*).

- **Šiuo** metu esu užsiėmęs. **Tuo** metu lijo. **Anais** laikais gyveno kitaip.
- Duok man **kitą** puodelį. **Kiti** studentai jau išėjo.

## Visas, kiekvienas

They decline like adjectives in -as (*geras*).

| Case | visas | visa | visi | visos |
|---|---|---|---|---|
| Vard. (nom.) | visas | visa | visi | visos |
| Kilm. (gen.) | viso | visos | visų | visų |
| Naud. (dat.) | visam | visai | visiems | visoms |
| Gal. (acc.) | visą | visą | visus | visas |
| Įnag. (instr.) | visu | visa | visais | visomis |
| Viet. (loc.) | visame | visoje | visuose | visose |

- **Visą** dieną lijo. Pasakyk **visiems** draugams. **Visoje** Lietuvoje šilta.
- **kiekvienas** is usually singular: **Kiekvieną** rytą bėgioju. **Kiekviename** kambaryje yra langas.
