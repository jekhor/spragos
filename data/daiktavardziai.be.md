# Daiktavardžiai — скланенне назоўнікаў

Назоўнікі падзяляюцца на **пяць тыпаў скланення** (*linksniuotės*). Тып пазнаюць па канчатку назоўнага склону адзіночнага ліку, а дзе ён неадназначны — па родным.

| Тып | Наз. скл. адз. л. | Род. скл. адз. л. | Прыклады |
|---|---|---|---|
| 1 | -as, -ias, -is, -ys (м. р.) | -o, -io | namas, kelias, brolis, traukinys |
| 2 | -a, -ia, -ė (ж. р.) | -os, -ios, -ės | knyga, bažnyčia, gatvė |
| 3 | -is (ж. р., некалькі м. р.) | -ies | šalis, naktis; м. р.: dantis, debesis |
| 4 | -us, -ius (м. р.) | -aus, -iaus | sūnus, turgus, vaisius |
| 5 | -uo (м. р.); sesuo, duktė (ж. р.) | -ens, -ers | akmuo, šuo; sesuo, duktė |

> **-is** бывае ў 1-м і 3-м тыпе: brolis — brol**io** (1), šalis — šal**ies** (3). **-ė** — у 2-м і 5-м: gatvė — gatv**ės** (2), duktė — dukt**ers** (5). У слоўніку побач з назоўным склонам даюць родны — запамінайце іх парай.

Як выбраць склон (пасля якіх прыназоўнікаў і дзеясловаў які склон патрэбны), глядзіце ў даведцы «Linksniai — склоны: пытанні і ўжыванне».

## 1. Мужчынскі род: -(i)as, -is, -ys

| Склон | Канчатак | namas | kelias | medis | traukinys |
|---|---|---|---|---|---|
| **адз. л.** | | | | | |
| Vard. (наз.) | -as, -ias, -is, -ys | namas | kelias | medis | traukinys |
| Kilm. (род.) | -o, -io | namo | kelio | medžio | traukinio |
| Naud. (дав.) | -ui, -iui | namui | keliui | medžiui | traukiniui |
| Gal. (він.) | -ą, -ią, -į | namą | kelią | medį | traukinį |
| Įnag. (твор.) | -u, -iu | namu | keliu | medžiu | traukiniu |
| Viet. (месн.) | -e, -yje | name | kelyje | medyje | traukinyje |
| **мн. л.** | | | | | |
| Vard. (наз.) | -ai, -iai | namai | keliai | medžiai | traukiniai |
| Kilm. (род.) | -ų, -ių | namų | kelių | medžių | traukinių |
| Naud. (дав.) | -ams, -iams | namams | keliams | medžiams | traukiniams |
| Gal. (він.) | -us, -ius | namus | kelius | medžius | traukinius |
| Įnag. (твор.) | -ais, -iais | namais | keliais | medžiais | traukiniais |
| Viet. (месн.) | -uose, -iuose | namuose | keliuose | medžiuose | traukiniuose |

- Месны склон адз. л.: **-e** у слоў на -as (nam**e**, miest**e**), **-yje** ў астатніх (kel**yje**, brol**yje**).
- **t → č, d → dž** перад *-io, -iui, -iu, -iai…*: medis → me**dž**io, dviratis → dvira**č**io. Перад *-į* і *-yje* змякчэння няма: medį, medyje. Гэтак жа, як medis, але без змякчэння, скланяецца brolis: brolio, broliui, brolį.

| **адз. л.** | | | | |

| Viet. (месн.) | -oje, -ioje, -ėje | knygoje | bažnyčioje | gatvėje |
| **мн. л.** | | | | |
| Vard. (наз.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Kilm. (род.) | -ų, -ių, -ių | knygų | bažnyčių | gatvių |
| Naud. (дав.) | -oms, -ioms, -ėms | knygoms | bažnyčioms | gatvėms |
| Gal. (він.) | -as, -ias, -es | knygas | bažnyčias | gatves |
| Įnag. (твор.) | -omis, -iomis, -ėmis | knygomis | bažnyčiomis | gatvėmis |

- Творны склон адз. л. у слоў на -a супадае з назоўным: Einu su mam**a**.
- Родны склон мн. л. у слоў на -ė — **-ių**, са змякчэннем: kėdė → kė**dž**ių, mergaitė → mergai**č**ių.
- Некалькі слоў мужчынскага роду скланяюцца гэтак жа: **dėdė** (дзядзька). Прыметнікі пры іх — мужчынскага роду: mano **mylimas** dėdė, du dėdes.

| **мн. л.** | | | | |
| Vard. (наз.) | -ys | šalys | naktys | dantys |
| Kilm. (род.) | -ių (часам -ų) | šalių | naktų | dantų |
| Naud. (дав.) | -ims | šalims | naktims | dantims |
| Gal. (він.) | -is | šalis | naktis | dantis |
| Įnag. (твор.) | -imis | šalimis | naktimis | dantimis |
| Viet. (месн.) | -yse | šalyse | naktyse | dantyse |

- Вінавальны склон мн. л. супадае з назоўным адз. л.: Aplankiau dvi naujas **šalis**.
- Давальны склон адз. л.: у жаночага роду **-iai** (šaliai, širdžiai), у мужчынскага **-iui** (dančiui, debesiui).
- Родны склон мн. л. звычайна **-ių** (šalių, širdžių, akių), але ў некаторых слоў **-ų**: naktų, ausų, žuvų, žąsų, dantų, debesų.
- Мужчынскага роду нямнога: dantis, debesis, žvėris; **vagis** — і мужчынскага, і жаночага.

| Viet. (месн.) | -uose, -iuose | sūnuose | turguose | vaisiuose |

- Словы на **-ius** у множным ліку скланяюцца як *kelias*: vaisiai, vaisiams, vaisiais.
- Супадаюць формы: **sūnus** — наз. скл. адз. л. і він. скл. мн. л. (Turime du **sūnus**); **vaisių** — він. скл. адз. л. і род. скл. мн. л.
- **žmogus** — у адз. л. як sūnus (žmogaus, žmogui, žmogumi), а ў мн. л. — **žmonės**: žmonių, žmonėms, žmones, žmonėmis, žmonėse.

- **mėnuo** — выключэнне: аснова *mėnes-* з канчаткамі 1-га тыпу (як brolis): mėnesio, mėnesiui, mėnesį, mėnesiu, mėnesyje; мн. л. mėnesiai, mėnesių…
