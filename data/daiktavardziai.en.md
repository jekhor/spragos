# Daiktavardžiai — noun declension

Nouns fall into **five declension types** (*linksniuotės*). The type is recognised by the nominative singular ending, and where that is ambiguous, by the genitive.

| Type | Nom. sg. | Gen. sg. | Examples |
|---|---|---|---|
| 1 | -as, -ias, -is, -ys (masc.) | -o, -io | namas, kelias, brolis, traukinys |
| 2 | -a, -ia, -ė (fem.) | -os, -ios, -ės | knyga, bažnyčia, gatvė |
| 3 | -is (fem., a few masc.) | -ies | šalis, naktis; masc.: dantis, debesis |
| 4 | -us, -ius (masc.) | -aus, -iaus | sūnus, turgus, vaisius |
| 5 | -uo (masc.); sesuo, duktė (fem.) | -ens, -ers | akmuo, šuo; sesuo, duktė |

> **-is** occurs in types 1 and 3: brolis — brol**io** (1), šalis — šal**ies** (3). **-ė** occurs in types 2 and 5: gatvė — gatv**ės** (2), duktė — dukt**ers** (5). Dictionaries give the genitive next to the nominative, so learn them as a pair.

To choose the case (which case follows which preposition or verb), see the reference “Linksniai — cases: questions and usage”.

## 1. Masculine: -(i)as, -is, -ys

| Case | Ending | namas | kelias | medis | traukinys |
|---|---|---|---|---|---|
| **singular** | | | | | |
| Vard. (nom.) | -as, -ias, -is, -ys | namas | kelias | medis | traukinys |
| Kilm. (gen.) | -o, -io | namo | kelio | medžio | traukinio |
| Naud. (dat.) | -ui, -iui | namui | keliui | medžiui | traukiniui |
| Gal. (acc.) | -ą, -ią, -į | namą | kelią | medį | traukinį |
| Įnag. (instr.) | -u, -iu | namu | keliu | medžiu | traukiniu |
| Viet. (loc.) | -e, -yje | name | kelyje | medyje | traukinyje |
| **plural** | | | | | |
| Vard. (nom.) | -ai, -iai | namai | keliai | medžiai | traukiniai |
| Kilm. (gen.) | -ų, -ių | namų | kelių | medžių | traukinių |
| Naud. (dat.) | -ams, -iams | namams | keliams | medžiams | traukiniams |
| Gal. (acc.) | -us, -ius | namus | kelius | medžius | traukinius |
| Įnag. (instr.) | -ais, -iais | namais | keliais | medžiais | traukiniais |
| Viet. (loc.) | -uose, -iuose | namuose | keliuose | medžiuose | traukiniuose |

- Locative singular: **-e** for nouns in -as (nam**e**, miest**e**), **-yje** for the rest (kel**yje**, brol**yje**).
- **t → č, d → dž** before *-io, -iui, -iu, -iai…*: medis → me**dž**io, dviratis → dvira**č**io. There is no softening before *-į* and *-yje*: medį, medyje. Brolis declines like medis, but without softening: brolio, broliui, brolį.

## 2. Feminine: -(i)a, -ė

| Case | Ending | knyga | bažnyčia | gatvė |
|---|---|---|---|---|
| **singular** | | | | |
| Vard. (nom.) | -a, -ia, -ė | knyga | bažnyčia | gatvė |
| Kilm. (gen.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Naud. (dat.) | -ai, -iai, -ei | knygai | bažnyčiai | gatvei |
| Gal. (acc.) | -ą, -ią, -ę | knygą | bažnyčią | gatvę |
| Įnag. (instr.) | -a, -ia, -e | knyga | bažnyčia | gatve |
| Viet. (loc.) | -oje, -ioje, -ėje | knygoje | bažnyčioje | gatvėje |
| **plural** | | | | |
| Vard. (nom.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Kilm. (gen.) | -ų, -ių, -ių | knygų | bažnyčių | gatvių |
| Naud. (dat.) | -oms, -ioms, -ėms | knygoms | bažnyčioms | gatvėms |
| Gal. (acc.) | -as, -ias, -es | knygas | bažnyčias | gatves |
| Įnag. (instr.) | -omis, -iomis, -ėmis | knygomis | bažnyčiomis | gatvėmis |
| Viet. (loc.) | -ose, -iose, -ėse | knygose | bažnyčiose | gatvėse |

- In nouns in -a, the instrumental singular is the same as the nominative: Einu su mam**a**.
- The genitive plural of nouns in -ė is **-ių**, with softening: kėdė → kė**dž**ių, mergaitė → mergai**č**ių.
- A few masculine nouns decline the same way: **dėdė** (uncle). Adjectives with them are masculine: mano **mylimas** dėdė, du dėdes.

## 3. -is: mostly feminine

| Case | Ending | šalis | naktis | dantis (masc.) |
|---|---|---|---|---|
| **singular** | | | | |
| Vard. (nom.) | -is | šalis | naktis | dantis |
| Kilm. (gen.) | -ies | šalies | nakties | danties |
| Naud. (dat.) | -iai; masc. -iui | šaliai | nakčiai | dančiui |
| Gal. (acc.) | -į | šalį | naktį | dantį |
| Įnag. (instr.) | -imi | šalimi | naktimi | dantimi |
| Viet. (loc.) | -yje | šalyje | naktyje | dantyje |
| **plural** | | | | |
| Vard. (nom.) | -ys | šalys | naktys | dantys |
| Kilm. (gen.) | -ių (sometimes -ų) | šalių | naktų | dantų |
| Naud. (dat.) | -ims | šalims | naktims | dantims |
| Gal. (acc.) | -is | šalis | naktis | dantis |
| Įnag. (instr.) | -imis | šalimis | naktimis | dantimis |
| Viet. (loc.) | -yse | šalyse | naktyse | dantyse |

- The accusative plural is the same as the nominative singular: Aplankiau dvi naujas **šalis**.
- Dative singular: **-iai** for feminine nouns (šaliai, širdžiai), **-iui** for masculine ones (dančiui, debesiui).
- The genitive plural is usually **-ių** (šalių, širdžių, akių), but some nouns take **-ų**: naktų, ausų, žuvų, žąsų, dantų, debesų.
- There are few masculine nouns: dantis, debesis, žvėris; **vagis** can be masculine or feminine.

## 4. Masculine: -(i)us

| Case | Ending | sūnus | turgus | vaisius |
|---|---|---|---|---|
| **singular** | | | | |
| Vard. (nom.) | -us, -ius | sūnus | turgus | vaisius |
| Kilm. (gen.) | -aus, -iaus | sūnaus | turgaus | vaisiaus |
| Naud. (dat.) | -ui, -iui | sūnui | turgui | vaisiui |
| Gal. (acc.) | -ų, -ių | sūnų | turgų | vaisių |
| Įnag. (instr.) | -umi, -iumi | sūnumi | turgumi | vaisiumi |
| Viet. (loc.) | -uje, -iuje | sūnuje | turguje | vaisiuje |
| **plural** | | | | |
| Vard. (nom.) | -ūs, -iai | sūnūs | turgūs | vaisiai |
| Kilm. (gen.) | -ų, -ių | sūnų | turgų | vaisių |
| Naud. (dat.) | -ums, -iams | sūnums | turgums | vaisiams |
| Gal. (acc.) | -us, -ius | sūnus | turgus | vaisius |
| Įnag. (instr.) | -umis, -iais | sūnumis | turgumis | vaisiais |
| Viet. (loc.) | -uose, -iuose | sūnuose | turguose | vaisiuose |

- Nouns in **-ius** decline like *kelias* in the plural: vaisiai, vaisiams, vaisiais.
- Identical forms: **sūnus** is both nominative singular and accusative plural (Turime du **sūnus**); **vaisių** is both accusative singular and genitive plural.
- **žmogus** declines like sūnus in the singular (žmogaus, žmogui, žmogumi), but its plural is **žmonės**: žmonių, žmonėms, žmones, žmonėmis, žmonėse.

## 5. -uo (masculine), sesuo, duktė

| Case | Ending | akmuo | šuo | sesuo | duktė |
|---|---|---|---|---|---|
| **singular** | | | | | |
| Vard. (nom.) | -uo, -ė | akmuo | šuo | sesuo | duktė |
| Kilm. (gen.) | -s | akmens | šuns | sesers | dukters |
| Naud. (dat.) | masc. -iui, fem. -iai | akmeniui | šuniui | seseriai | dukteriai |
| Gal. (acc.) | -į | akmenį | šunį | seserį | dukterį |
| Įnag. (instr.) | masc. -iu (šuo: -imi), fem. -imi, -ia | akmeniu | šunimi / šuniu | seserimi / seseria | dukterimi / dukteria |
| Viet. (loc.) | -yje | akmenyje | šunyje | seseryje | dukteryje |
| **plural** | | | | | |
| Vard. (nom.) | -ys | akmenys | šunys | seserys | dukterys |
| Kilm. (gen.) | -ų | akmenų | šunų | seserų | dukterų |
| Naud. (dat.) | -ims | akmenims | šunims | seserims | dukterims |
| Gal. (acc.) | -is | akmenis | šunis | seseris | dukteris |
| Įnag. (instr.) | -imis | akmenimis | šunimis | seserimis | dukterimis |
| Viet. (loc.) | -yse | akmenyse | šunyse | seseryse | dukteryse |

- The endings are added to a stem with **-en-** (masculine) or **-er-** (sesuo, duktė): akmen-, vanden-, šun-, seser-, dukter- → vand**en**į, ses**er**į. Vanduo, ruduo and asmuo decline like akmuo.
- **mėnuo** is an exception: the stem *mėnes-* takes type 1 endings (like brolis): mėnesio, mėnesiui, mėnesį, mėnesiu, mėnesyje; plural mėnesiai, mėnesių…
