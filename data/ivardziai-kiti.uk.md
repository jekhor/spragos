# Įvardžiai — вказівні та інші займенники

Тут зібрано займенники (*įvardžiai*), крім особових:
- **вказівні** — šis, tas, anas, toks;
- **питальні й відносні** — kuris, koks;
- **означальні** — pats, visas, kiekvienas, kitas;
- **заперечний** — joks.

Усі вони змінюються за родами, числами й відмінками та узгоджуються з іменником, як прикметники:

| Слово | Значення | Тип |
|---|---|---|
| kuris, kuri | котрий, який (з відомих) | питальний і відносний |
| koks, kokia | який (яка якість) | питальний |
| toks, tokia | такий | вказівний |
| joks, jokia | жодний | заперечний |
| šis, ši | цей | вказівний |
| tas, ta | той | вказівний |
| anas, ana | той (далекий, «онде той») | вказівний |
| kitas, kita | інший | означальний |
| pats, pati | сам; той самий | означальний |
| visas, visa | весь | означальний |
| kiekvienas, kiekviena | кожний | означальний |

## Kuris, kuri

Відмінюється так само, як *jis / ji*: kur**iuo** — як j**uo**, kur**iuos** — як j**uos**.

| Відмінок | ч. р. | ж. р. | ч. р. мн. | ж. р. мн. |
|---|---|---|---|---|
| Vardininkas (наз., kas?) | kuris | kuri | kurie | kurios |
| Kilmininkas (род., ko?) | kurio | kurios | kurių | kurių |
| Naudininkas (дав., kam?) | kuriam | kuriai | kuriems | kurioms |
| Galininkas (знах., ką?) | kurį | kurią | kuriuos | kurias |
| Įnagininkas (ор., kuo?) | kuriuo | kuria | kuriais | kuriomis |
| Vietininkas (місц., kur?) | kuriame | kurioje | kuriuose | kuriose |

**У підрядному реченні** (*namas, kuriame gyvenu* — «будинок, у якому я живу»):
- **рід і число** *kuris* бере від слова, до якого належить: *namas* → kuris, *knyga* → kuri, *vaikai* → kurie;
- **відмінок** визначає його роль у підрядному реченні — дієслово або прийменник.

| Приклад | Чому цей відмінок |
|---|---|
| Tai knyga, **kurią** skaitau. | skaityti ką? — знахідний |
| Tai draugas, **kurio** seniai nemačiau. | заперечення — родовий |
| Mergina, su **kuria** kalbėjau, — mano sesuo. | su + орудний |
| Namas, **kuriame** gyvenu, labai senas. | де? — місцевий |
| Vaikai, **kuriems** patinka sportas, lanko baseiną. | patikti kam? — давальний |

> Перед *kuris* у підрядному реченні завжди ставиться кома. Якщо підрядне речення стоїть у середині, кома потрібна і після нього.

## Kuris чи koks?

- **kuris** — «котрий» з кількох відомих: *Kurią knygą imsi — šitą ar aną?*
- **koks** — «який», питання про якість: *Kokią knygą skaitai? — Įdomią.*

У питаннях часто підходять обидва: *Kuriame / Kokiame name gyveni?*

## Koks, toks, joks

Ці три слова відмінюються однаково. Майже всі форми — як у прикметника *žalias* (kok**io**, kok**iam**, kok**ią**…). Відрізняються лише три форми: називний однини **koks**, знахідний однини ч. р. **kokį**, називний множини ч. р. **kokie**.

| Відмінок | ч. р. | ж. р. | ч. р. мн. | ж. р. мн. |
|---|---|---|---|---|
| Vard. (наз.) | koks | kokia | kokie | kokios |
| Kilm. (род.) | kokio | kokios | kokių | kokių |
| Naud. (дав.) | kokiam | kokiai | kokiems | kokioms |
| Gal. (знах.) | kokį | kokią | kokius | kokias |
| Įnag. (ор.) | kokiu | kokia | kokiais | kokiomis |
| Viet. (місц.) | kokiame | kokioje | kokiuose | kokiose |

- **toks** — такий: Niekada nemačiau **tokio** gražaus ežero.
- **joks** — жодний; майже завжди із запереченням, тому найчастіше в родовому: Neturiu **jokio** noro. Nėra **jokių** problemų.

## Pats, pati

| Відмінок | ч. р. | ж. р. | ч. р. мн. | ж. р. мн. |
|---|---|---|---|---|
| Vard. (наз.) | pats | pati | **patys** | pačios |
| Kilm. (род.) | **paties** | pačios | pačių | pačių |
| Naud. (дав.) | pačiam | pačiai | **patiems** | pačioms |
| Gal. (знах.) | **patį** | pačią | pačius | pačias |
| Įnag. (ор.) | pačiu | pačia | pačiais | pačiomis |
| Viet. (місц.) | pačiame | pačioje | pačiuose | pačiose |

Жирним виділено форми, які найчастіше плутають.

- **pats / pati** — «сам»: Aš **pati** pasiuvau suknelę. Kalbėjau su **pačiu** direktoriumi.
- **tas pats / ta pati** — «той самий», відмінюються обидві частини: Gyvename **tame pačiame** name. Važiavome **tuo pačiu** autobusu.
- **toks pats / tokia pati** — «такий самий»: Turiu **tokius pačius** batus kaip tu.
- **pačiame / pačioje** + місце або час — «у самому…»: **pačiame** centre, **pačioje** pradžioje.

## Šis, tas, anas, kitas

- **šis** — «цей», близький предмет;
- **tas** — «той»;
- **anas** — «той, далекий»: зазвичай протиставляється *šis* (*šis namas, o anas…*) або вживається в усталених виразах: *anoje pusėje* (на тому боці), *anais laikais* (за давніх часів), *aną dieną* (нещодавно), *anuo metu* (у той час).

*Tas* і *anas* відмінюються однаково, *šis* — майже так само, але з -i- в основі. *Kitas* відмінюється як звичайний прикметник на -as (*geras*): **kitu**, **kiti**, **kitus** — а не «kituo», «kitie», «kituos», як підказує схожість із *tas*.

|---|---|---|---|---|
| **однина** | | | | |
| Vard. (наз.) | šis | tas | anas | kitas |
| Kilm. (род.) | šio | to | ano | kito |
| Naud. (дав.) | šiam | tam | anam | kitam |
| Gal. (знах.) | šį | tą | aną | kitą |
| Įnag. (ор.) | šiuo | tuo | anuo | **kitu** |
| Viet. (місц.) | šiame | tame | aname | kitame |
| **множина** | | | | |
| Vard. (наз.) | šie | tie | anie | **kiti** |
| Kilm. (род.) | šių | tų | anų | kitų |
| Naud. (дав.) | šiems | tiems | aniems | kitiems |
| Gal. (знах.) | šiuos | tuos | anuos | **kitus** |

| Відмінок | ši | ta | ana | kita |
|---|---|---|---|---|
| **однина** | | | | |
| Vard. (наз.) | ši | ta | ana | kita |
| Kilm. (род.) | šios | tos | anos | kitos |
| Naud. (дав.) | šiai | tai | anai | kitai |
| Gal. (знах.) | šią | tą | aną | kitą |
| Įnag. (ор.) | šia | ta | ana | kita |
| Viet. (місц.) | šioje | toje | anoje | kitoje |
| **множина** | | | | |
| Vard. (наз.) | šios | tos | anos | kitos |
| Kilm. (род.) | šių | tų | anų | kitų |
| Naud. (дав.) | šioms | toms | anoms | kitoms |
| Gal. (знах.) | šias | tas | anas | kitas |
| Įnag. (ор.) | šiomis | tomis | anomis | kitomis |
| Viet. (місц.) | šiose | tose | anose | kitose |

> Будьте уважні з омонімами: **tai** — це і давальний відмінок *ta* (*tai moteriai* — «тій жінці»), і частка «це» (*Tai mano namas*). **Tas** — і називний чоловічого роду, і знахідний жіночого в множині (*tas knygas*).

- **Šiuo** metu esu užsiėmęs. **Tuo** metu lijo. **Anais** laikais gyveno kitaip.
- Duok man **kitą** puodelį. **Kiti** studentai jau išėjo.

## Visas, kiekvienas

Відмінюються як прикметники на -as (*geras*).

| Відмінок | visas | visa | visi | visos |
|---|---|---|---|---|
| Vard. (наз.) | visas | visa | visi | visos |
| Kilm. (род.) | viso | visos | visų | visų |
| Naud. (дав.) | visam | visai | visiems | visoms |
| Gal. (знах.) | visą | visą | visus | visas |
| Įnag. (ор.) | visu | visa | visais | visomis |
| Viet. (місц.) | visame | visoje | visuose | visose |

- **Visą** dieną lijo. Pasakyk **visiems** draugams. **Visoje** Lietuvoje šilta.
- **kiekvienas** зазвичай в однині: **Kiekvieną** rytą bėgioju. **Kiekviename** kambaryje yra langas.
