# Тренажёр литовской грамматики

Упражнение «вставь пропущенное слово»: над текстом показывается банк слов, слова перетаскиваются в пропуски (или: тап по слову → тап по пропуску). Ответы проверяются кнопкой «Проверить».

## Запуск

```bash
python3 serve.py
```

Откройте http://localhost:8000/. Нужен только Python 3, без дополнительных пакетов.

- Другой порт: `python3 serve.py --port 8080`
- Доступ с телефона в той же сети: `python3 serve.py --host 0.0.0.0`, затем откройте `http://<IP компьютера>:8000/`

Статистика и настройки хранятся в браузере (localStorage), отдельно для каждого браузера и устройства.

## Как пополнять базу

Чтобы сгенерировать новые задания с помощью LLM, передайте ей [MATERIALS_GUIDE.md](MATERIALS_GUIDE.md) и в конце напишите тему. Шаблон запроса — в конце файла.

Каждая тема — это файл `.txt` в папке `data/` (можно раскладывать по подпапкам). Чтобы добавить тему или задания, создайте или отредактируйте файл и обновите страницу в браузере. Перезапускать сервер не нужно.

Если в файле ошибка разметки, страница покажет её вверху с именем файла и номером строки. Остальные задания при этом работают.

### Формат файла

```
@title: Įvardžiai — местоимения
@group: Склонение
@description: Личные и указательные местоимения
@distractors: jo, jam, jį, juo, jame

# Строки, начинающиеся с #, — комментарии.

Aš {jį|jis} matau kiekvieną dieną.
Ar kalbėjai su {ja|ji|jai, ją, jos}?
Važiuoju {į mokyklą/mokyklon|mokykla}.

--- Mano šeima
Tai mano sesuo. {Ją|ji} vadina Ona.
Aš {jai|ji} dažnai skambinu.
---
```

**Заголовок** (все строки необязательны):

| Строка | Значение |
|---|---|
| `@title:` | Название темы в списке (по умолчанию — имя файла) |
| `@group:` | Группа, под которой тема показана в списке |
| `@description:` | Короткое пояснение под названием |
| `@distractors:` | Общий запас «лишних» форм для банка слов, через запятую |
| `@hints: always` | Показывать подсказки в этой теме всегда, даже если в настройках они выключены. Нужно там, где без подсказки ответ неоднозначен: в «Vaikai žaidžia ___ parke» подходит и žaliame, и dideliame |

**Задания:**

- Каждая строка — отдельное предложение. В нём должен быть хотя бы один пропуск.
- Связный текст заключается между строкой `--- Заголовок` и строкой `---`. Каждая строка внутри становится абзацем, а весь текст считается одним заданием. Строки без пропусков внутри текста допустимы.

**Пропуск** — `{ответ|подсказка|лишние, формы}`:

| Запись | Смысл |
|---|---|
| `{jį}` | Только ответ |
| `{jį\|jis}` | Ответ + начальная форма (показывается мелко под пропуском) |
| `{jį\|jis\|jam, jo}` | + свои «лишние» формы для банка слов |
| `{į mokyklą/mokyklon\|mokykla}` | Несколько правильных вариантов через `/`. В банк попадает первый |
| `{jį\|\|jam, jo}` | Лишние формы без подсказки |

Старайтесь, чтобы ответ однозначно следовал из предложения. Например, не «Aš {jį} matau», а «Tai mano brolis. Aš {jį|jis} matau». Где по смыслу годятся два слова, перечислите оба через `/`: `{šį/tą|šis}`.

Регистр при проверке не учитывается. Если ответ стоит в начале предложения, пишите его с заглавной буквы (`{Ją|ji}`): лишние формы для такого пропуска тоже покажутся с заглавной.

Фигурную скобку как обычный символ можно записать как `\{` и `\}`.

### Откуда берутся лишние формы

В настройках раунда можно выбрать «Банк слов: + лишние формы». Тогда к каждому пропуску добавляются 1–2 неправильных варианта. Источники в порядке приоритета:

1. формы, явно указанные в самом пропуске (`{…|…|a, b}`);
2. ответы других пропусков этой темы с той же подсказкой. Например, для `{jį|jis}` возьмутся `jam`, `jo`, `juo` из других предложений с подсказкой `jis`. Поэтому подсказки стоит писать единообразно;
3. общий список `@distractors` темы.

## Размер раунда

В настройках задаётся примерное число пропусков в раунде. Задания набираются случайно, пока не наберётся нужное число. Длинный текст, с которым получился бы заметный перебор, пропускается. Если подходят только длинные тексты, раунд состоит из одного текста целиком.

## Устройство

```
serve.py            сервер: раздаёт web/ и data/, GET /api/files — список тем
web/index.html      страница
web/style.css
web/js/parser.js    разбор файлов тем
web/js/round.js     сборка раунда, банк слов, проверка
web/js/dnd.js       перетаскивание (мышь и сенсорный экран)
web/js/stats.js     статистика и настройки в localStorage
web/js/app.js       интерфейс
data/*.txt          база заданий
tests/              тесты: node --test
```

Задания, в которых были ошибки, в следующих раундах попадаются чаще.

## Тесты

```bash
node --test
```

Тесты проверяют разбор формата, сборку раунда и то, что все файлы в `data/` разбираются без ошибок.
