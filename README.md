# Spragos — тренажёр литовской грамматики

*Spragos* по-литовски значит «пропуски»: и в тексте, и в знаниях.

Упражнение «вставь пропущенное слово». Ответы проверяются кнопкой «Проверить». Есть два режима, переключаются в настройках раунда:
- **Перетаскивание.** Над текстом показывается банк слов; слова перетаскиваются в пропуски, или можно нажать на слово, а потом на пропуск.
- **Одно слово.** В настройках раунда можно выбрать конкретное слово (лемму из подсказок), например *jis*, *gražus* или *kuris*, и тренировать только его формы. В раунд попадут задания с этим словом; остальные пропуски в них будут уже заполнены, а лишние формы в банке — только формы этого слова.
- **Ввод с клавиатуры.** Слово вписывается прямо в пропуск. Для литовских букв (ą č ę ė į š ų ū ž) над текстом есть панель. Регистр не важен, диакритика важна: «ja» и «ją» — разные формы. Enter переходит к следующему пустому полю, а на последнем запускает проверку. Во время упражнения можно открыть грамматическую справку по теме: таблицы форм во всплывающем окне.

## Запуск

```bash
python3 serve.py
```

Откройте http://localhost:8000/. Нужен только Python 3, без дополнительных пакетов.

- Другой порт: `python3 serve.py --port 8080`
- Доступ с телефона в той же сети: `python3 serve.py --host 0.0.0.0`, затем откройте `http://<IP компьютера>:8000/`

Статистика и настройки хранятся в браузере (localStorage), отдельно для каждого браузера и устройства.

## Публикация

Сайт: **https://jekhor.github.io/spragos/**

Сайт обновляется сам при каждом push в `main`. Workflow `.github/workflows/pages.yml`:
1. прогоняет тесты (`node --test`);
2. собирает статическую версию командой `python3 build.py`. Она складывает `web/` и `data/` в одну папку и создаёт `data/index.json` со списком файлов базы вместо `/api/files`;
3. публикует результат на GitHub Pages.

Если тесты падают, сайт не обновляется.

Собрать статическую версию локально, например для другого хостинга:

```bash
python3 build.py _site
```

## Как пополнять базу

Чтобы сгенерировать новые задания с помощью LLM, передайте ей [MATERIALS_GUIDE.md](MATERIALS_GUIDE.md) и в конце напишите тему. Шаблон запроса — в конце файла.

Каждая тема — это файл `.txt` в папке `data/` (можно раскладывать по подпапкам). Чтобы добавить тему или задания, создайте или отредактируйте файл и обновите страницу в браузере. Перезапускать сервер не нужно.

Если в файле ошибка разметки, страница покажет её вверху с именем файла и номером строки. Остальные задания при этом работают.

### Формат файла

```
@title: Įvardžiai — местоимения
@group: Склонение
@description: Личные и указательные местоимения
@distractors: jo, jam, jį, juo, jame

# Строки, начинающиеся с #, — комментарии.

Aš {jį|jis} matau kiekvieną dieną.
Ar kalbėjai su {ja|ji|jai, ją, jos}?
Važiuoju {į mokyklą/mokyklon|mokykla}.

--- Mano šeima
Tai mano sesuo. {Ją|ji} vadina Ona.
Aš {jai|ji} dažnai skambinu.
---
```

**Заголовок** (все строки необязательны):

| Строка | Значение |
|---|---|
| `@title:` | Название темы в списке (по умолчанию — имя файла) |
| `@group:` | Группа, под которой тема показана в списке |
| `@description:` | Короткое пояснение под названием |
| `@distractors:` | Общий запас «лишних» форм для банка слов, через запятую |
| `@reference:` | Путь к файлу справки относительно `data/`, если он называется не так, как тема (см. ниже) |
| `@subtopic:` | Начало подтемы: `@subtopic: Заголовок \| пояснение`. Пояснение необязательно. См. «Подтемы» ниже |
| `@word-practice: off` | Не предлагать для этой темы тренировку одного слова (например, у существительных слов слишком много) |
| `@hints: always` | Показывать подсказки в этой теме всегда, даже если в настройках они выключены. Нужно там, где без подсказки ответ неоднозначен: в «Vaikai žaidžia ___ parke» подходит и žaliame, и dideliame |

**Задания:**

- Каждая строка — отдельное предложение. В нём должен быть хотя бы один пропуск.
- Связный текст заключается между строкой `--- Заголовок` и строкой `---`. Каждая строка внутри становится абзацем, а весь текст считается одним заданием. Строки без пропусков внутри текста допустимы.

**Пропуск** — `{ответ|подсказка|лишние, формы}`:

| Запись | Смысл |
|---|---|
| `{jį}` | Только ответ |
| `{jį\|jis}` | Ответ + начальная форма (показывается мелко под пропуском) |
| `{jį\|jis\|jam, jo}` | + свои «лишние» формы для банка слов |
| `{į mokyklą/mokyklon\|mokykla}` | Несколько правильных вариантов через `/`. В банк попадает первый |
| `{jį\|\|jam, jo}` | Лишние формы без подсказки |

Старайтесь, чтобы ответ однозначно следовал из предложения. Например, не «Aš {jį} matau», а «Tai mano brolis. Aš {jį|jis} matau». Где по смыслу годятся два слова, перечислите оба через `/`: `{šį/tą|šis}`.

Регистр при проверке не учитывается. Если ответ стоит в начале предложения, пишите его с заглавной буквы (`{Ją|ji}`): лишние формы для такого пропуска тоже покажутся с заглавной.

Фигурную скобку как обычный символ можно записать как `\{` и `\}`.

### Подтемы

Тему можно разбить на подтемы, например склонение существительных — на пять типов склонения. Строка `@subtopic: Заголовок | пояснение` начинает подтему: к ней относятся все задания ниже, до следующей `@subtopic`. Если в файле есть подтемы, задания до первой из них считаются ошибкой.

```
@title: Daiktavardžiai — существительные
@word-practice: off

@subtopic: 1. мужской род, -(i)as, -is, -ys | namas, kelias, brolis
Mes gyvename tame dideliame {name|namas}.

@subtopic: 2. женский род, -(i)a, -ė | knyga, bažnyčia, gatvė
Ši {knyga|knyga} labai įdomi.
```

В настройках подтемы показаны под темой с отдельными флажками: можно отметить тему целиком или только нужные подтемы. Статистика ведётся по каждой подтеме. Если заголовок подтемы начинается с номера («1. …»), в заголовке раунда показываются номера выбранных подтем.

### Откуда берутся лишние формы

В настройках раунда можно выбрать «Банк слов: + лишние формы». Тогда к каждому пропуску добавляются 1–2 неправильных варианта. Источники в порядке приоритета:

1. формы, явно указанные в самом пропуске (`{…|…|a, b}`);
2. ответы других пропусков этой темы с той же подсказкой. Например, для `{jį|jis}` возьмутся `jam`, `jo`, `juo` из других предложений с подсказкой `jis`. Поэтому подсказки стоит писать единообразно;
3. общий список `@distractors` темы.

## Грамматическая справка

Справка — это файл `.md` в папке `data/`, написанный в Markdown. Если он называется так же, как файл темы (`ivardziai.txt` → `ivardziai.md`), он автоматически привязывается к теме:
- в списке тем рядом с ней появляется ссылка «справка»;
- в раунде появляется кнопка «справка». Если в раунде несколько тем, их справки открываются во вкладках.

Справку с другим именем (например, одну на несколько тем) подключают строкой `@reference: путь/к/файлу.md` в заголовке темы. Все справки, в том числе не привязанные ни к одной теме (например, `linksniai.md` — обзор падежей), перечислены в разделе «Справка» в верхнем меню.

Первая строка `# Заголовок` становится заголовком окна. Поддерживаемая разметка:
- заголовки `##`, `###`;
- абзацы, списки `-` и `1.`;
- таблицы `| … |`;
- врезки `> …`;
- `**жирный**` — удобно выделять окончания: `ger**as**`;
- `*курсив*`, `` `код` ``.

## Размер раунда

В настройках задаётся примерное число пропусков в раунде. Задания набираются случайно, пока не наберётся нужное число. Длинный текст, с которым получился бы заметный перебор, пропускается. Если подходят только длинные тексты, раунд состоит из одного текста целиком.

## Устройство

```
serve.py            сервер: раздаёт web/ и data/, GET /api/files — список тем и справок
build.py            сборка статической версии для GitHub Pages (_site/)
tools/make_og_image.py  картинка предпросмотра ссылки web/og-image.png
.github/workflows/  тесты и публикация на GitHub Pages
web/index.html      страница
web/style.css
web/js/parser.js    разбор файлов тем
web/js/round.js     сборка раунда, банк слов, проверка
web/js/dnd.js       перетаскивание (мышь и сенсорный экран)
web/js/stats.js     статистика и настройки в localStorage
web/js/markdown.js  рендерер Markdown для справок
web/js/app.js       интерфейс
data/*.txt          база заданий
data/*.md           грамматические справки
tests/              тесты: node --test
```

Задания, в которых были ошибки, в следующих раундах попадаются чаще.

## Тесты

```bash
node --test
```

Тесты проверяют разбор формата, сборку раунда и саму базу:
- все файлы в `data/` разбираются без ошибок;
- каждый ответ — существующая форма своей подсказки по таблицам склонения из `tests/paradigms.mjs` (местоимения, числительные, прилагательные, существительные — по типу склонения из номера подтемы);
- пропусков, где ответ совпадает с подсказкой, не больше 10% темы;
- предложения не повторяются.
