# Daiktavardžiai — склонение существительных

Существительные делятся на **пять типов склонения** (*linksniuotės*). Тип узнаётся по окончанию именительного падежа ед. ч., а где оно неоднозначно — по родительному.

| Тип | Им. п. ед. ч. | Род. п. ед. ч. | Примеры |
|---|---|---|---|
| 1 | -as, -ias, -is, -ys (м. р.) | -o, -io | namas, kelias, brolis, traukinys |
| 2 | -a, -ia, -ė (ж. р.) | -os, -ios, -ės | knyga, bažnyčia, gatvė |
| 3 | -is (ж. р., несколько м. р.) | -ies | šalis, naktis; м. р.: dantis, debesis |
| 4 | -us, -ius (м. р.) | -aus, -iaus | sūnus, turgus, vaisius |
| 5 | -uo (м. р.); sesuo, duktė (ж. р.) | -ens, -ers | akmuo, šuo; sesuo, duktė |

> **-is** бывает в 1-м и 3-м типе: brolis — brol**io** (1), šalis — šal**ies** (3). **-ė** — во 2-м и 5-м: gatvė — gatv**ės** (2), duktė — dukt**ers** (5). В словаре рядом с именительным падежом дают родительный — запоминайте их парой.

Как выбрать падеж (после каких предлогов и глаголов какой падеж нужен), смотрите в справке «Linksniai — падежи: вопросы и употребление».

## 1. Мужской род: -(i)as, -is, -ys

| Падеж | Окончание | namas | kelias | medis | traukinys |
|---|---|---|---|---|---|
| **ед. ч.** | | | | | |
| Vard. (им.) | -as, -ias, -is, -ys | namas | kelias | medis | traukinys |
| Kilm. (род.) | -o, -io | namo | kelio | medžio | traukinio |
| Naud. (дат.) | -ui, -iui | namui | keliui | medžiui | traukiniui |
| Gal. (вин.) | -ą, -ią, -į | namą | kelią | medį | traukinį |
| Įnag. (твор.) | -u, -iu | namu | keliu | medžiu | traukiniu |
| Viet. (местн.) | -e, -yje | name | kelyje | medyje | traukinyje |
| **мн. ч.** | | | | | |
| Vard. (им.) | -ai, -iai | namai | keliai | medžiai | traukiniai |
| Kilm. (род.) | -ų, -ių | namų | kelių | medžių | traukinių |
| Naud. (дат.) | -ams, -iams | namams | keliams | medžiams | traukiniams |
| Gal. (вин.) | -us, -ius | namus | kelius | medžius | traukinius |
| Įnag. (твор.) | -ais, -iais | namais | keliais | medžiais | traukiniais |
| Viet. (местн.) | -uose, -iuose | namuose | keliuose | medžiuose | traukiniuose |

- Местный падеж ед. ч.: **-e** у слов на -as (nam**e**, miest**e**), **-yje** у остальных (kel**yje**, brol**yje**).
- **t → č, d → dž** перед *-io, -iui, -iu, -iai…*: medis → me**dž**io, dviratis → dvira**č**io. Перед *-į* и *-yje* смягчения нет: medį, medyje. Так же, как medis, но без смягчения, склоняется brolis: brolio, broliui, brolį.

## 2. Женский род: -(i)a, -ė

| Падеж | Окончание | knyga | bažnyčia | gatvė |
|---|---|---|---|---|
| **ед. ч.** | | | | |
| Vard. (им.) | -a, -ia, -ė | knyga | bažnyčia | gatvė |
| Kilm. (род.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Naud. (дат.) | -ai, -iai, -ei | knygai | bažnyčiai | gatvei |
| Gal. (вин.) | -ą, -ią, -ę | knygą | bažnyčią | gatvę |
| Įnag. (твор.) | -a, -ia, -e | knyga | bažnyčia | gatve |
| Viet. (местн.) | -oje, -ioje, -ėje | knygoje | bažnyčioje | gatvėje |
| **мн. ч.** | | | | |
| Vard. (им.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Kilm. (род.) | -ų, -ių, -ių | knygų | bažnyčių | gatvių |
| Naud. (дат.) | -oms, -ioms, -ėms | knygoms | bažnyčioms | gatvėms |
| Gal. (вин.) | -as, -ias, -es | knygas | bažnyčias | gatves |
| Įnag. (твор.) | -omis, -iomis, -ėmis | knygomis | bažnyčiomis | gatvėmis |
| Viet. (местн.) | -ose, -iose, -ėse | knygose | bažnyčiose | gatvėse |

- Творительный ед. ч. у слов на -a совпадает с именительным: Einu su mam**a**.
- Родительный мн. ч. у слов на -ė — **-ių**, со смягчением: kėdė → kė**dž**ių, mergaitė → mergai**č**ių.
- Несколько слов мужского рода склоняются так же: **dėdė** (дядя). Прилагательные при них — мужского рода: mano **mylimas** dėdė, du dėdes.

## 3. -is: в основном женский род

| Падеж | Окончание | šalis | naktis | dantis (м. р.) |
|---|---|---|---|---|
| **ед. ч.** | | | | |
| Vard. (им.) | -is | šalis | naktis | dantis |
| Kilm. (род.) | -ies | šalies | nakties | danties |
| Naud. (дат.) | -iai; м. р. -iui | šaliai | nakčiai | dančiui |
| Gal. (вин.) | -į | šalį | naktį | dantį |
| Įnag. (твор.) | -imi | šalimi | naktimi | dantimi |
| Viet. (местн.) | -yje | šalyje | naktyje | dantyje |
| **мн. ч.** | | | | |
| Vard. (им.) | -ys | šalys | naktys | dantys |
| Kilm. (род.) | -ių (иногда -ų) | šalių | naktų | dantų |
| Naud. (дат.) | -ims | šalims | naktims | dantims |
| Gal. (вин.) | -is | šalis | naktis | dantis |
| Įnag. (твор.) | -imis | šalimis | naktimis | dantimis |
| Viet. (местн.) | -yse | šalyse | naktyse | dantyse |

- Винительный мн. ч. совпадает с именительным ед. ч.: Aplankiau dvi naujas **šalis**.
- Дательный ед. ч.: у женского рода **-iai** (šaliai, širdžiai), у мужского **-iui** (dančiui, debesiui).
- Родительный мн. ч. обычно **-ių** (šalių, širdžių, akių), но у некоторых слов **-ų**: naktų, ausų, žuvų, žąsų, dantų, debesų.
- Мужского рода немного: dantis, debesis, žvėris; **vagis** — и мужского, и женского.

## 4. Мужской род: -(i)us

| Падеж | Окончание | sūnus | turgus | vaisius |
|---|---|---|---|---|
| **ед. ч.** | | | | |
| Vard. (им.) | -us, -ius | sūnus | turgus | vaisius |
| Kilm. (род.) | -aus, -iaus | sūnaus | turgaus | vaisiaus |
| Naud. (дат.) | -ui, -iui | sūnui | turgui | vaisiui |
| Gal. (вин.) | -ų, -ių | sūnų | turgų | vaisių |
| Įnag. (твор.) | -umi, -iumi | sūnumi | turgumi | vaisiumi |
| Viet. (местн.) | -uje, -iuje | sūnuje | turguje | vaisiuje |
| **мн. ч.** | | | | |
| Vard. (им.) | -ūs, -iai | sūnūs | turgūs | vaisiai |
| Kilm. (род.) | -ų, -ių | sūnų | turgų | vaisių |
| Naud. (дат.) | -ums, -iams | sūnums | turgums | vaisiams |
| Gal. (вин.) | -us, -ius | sūnus | turgus | vaisius |
| Įnag. (твор.) | -umis, -iais | sūnumis | turgumis | vaisiais |
| Viet. (местн.) | -uose, -iuose | sūnuose | turguose | vaisiuose |

- Слова на **-ius** во множественном числе склоняются как *kelias*: vaisiai, vaisiams, vaisiais.
- Совпадают формы: **sūnus** — им. п. ед. ч. и вин. п. мн. ч. (Turime du **sūnus**); **vaisių** — вин. п. ед. ч. и род. п. мн. ч.
- **žmogus** — в ед. ч. как sūnus (žmogaus, žmogui, žmogumi), а во мн. ч. — **žmonės**: žmonių, žmonėms, žmones, žmonėmis, žmonėse.

## 5. -uo (мужской род), sesuo, duktė

| Падеж | Окончание | akmuo | šuo | sesuo | duktė |

| **ед. ч.** | | | | | |

| Įnag. (твор.) | м. р. -iu (šuo: -imi), ж. р. -imi, -ia | akmeniu | šunimi / šuniu | seserimi / seseria | dukterimi / dukteria |
| Viet. (местн.) | -yje | akmenyje | šunyje | seseryje | dukteryje |
| **мн. ч.** | | | | | |
| Vard. (им.) | -ys | akmenys | šunys | seserys | dukterys |
| Kilm. (род.) | -ų | akmenų | šunų | seserų | dukterų |
| Naud. (дат.) | -ims | akmenims | šunims | seserims | dukterims |
| Gal. (вин.) | -is | akmenis | šunis | seseris | dukteris |
| Įnag. (твор.) | -imis | akmenimis | šunimis | seserimis | dukterimis |
| Viet. (местн.) | -yse | akmenyse | šunyse | seseryse | dukteryse |

- Окончания присоединяются к основе с **-en-** (м. р.) или **-er-** (sesuo, duktė): akmen-, vanden-, šun-, seser-, dukter- → vand**en**į, ses**er**į. Так же, как akmuo, склоняются vanduo, ruduo, asmuo.
- **mėnuo** — исключение: основа *mėnes-* с окончаниями 1-го типа (как brolis): mėnesio, mėnesiui, mėnesį, mėnesiu, mėnesyje; мн. ч. mėnesiai, mėnesių…
