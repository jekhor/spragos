# Daiktavardžiai — відмінювання іменників

Іменники поділяються на **п’ять типів відмінювання** (*linksniuotės*). Тип визначають за закінченням називного відмінка однини, а де воно неоднозначне — за родовим.

| Тип | Наз. в. одн. | Род. в. одн. | Приклади |
|---|---|---|---|
| 1 | -as, -ias, -is, -ys (ч. р.) | -o, -io | namas, kelias, brolis, traukinys |
| 2 | -a, -ia, -ė (ж. р.) | -os, -ios, -ės | knyga, bažnyčia, gatvė |
| 3 | -is (ж. р., кілька ч. р.) | -ies | šalis, naktis; ч. р.: dantis, debesis |
| 4 | -us, -ius (ч. р.) | -aus, -iaus | sūnus, turgus, vaisius |
| 5 | -uo (ч. р.); sesuo, duktė (ж. р.) | -ens, -ers | akmuo, šuo; sesuo, duktė |

> **-is** буває в 1-му і 3-му типі: brolis — brol**io** (1), šalis — šal**ies** (3). **-ė** — у 2-му і 5-му: gatvė — gatv**ės** (2), duktė — dukt**ers** (5). У словнику поруч із називним відмінком подають родовий — запам’ятовуйте їх парою.

Як вибрати відмінок (після яких прийменників і дієслів який відмінок потрібен), дивіться в довідці «Linksniai — відмінки: питання і вживання».

## 1. Чоловічий рід: -(i)as, -is, -ys

| Відмінок | Закінчення | namas | kelias | medis | traukinys |
|---|---|---|---|---|---|
| **однина** | | | | | |
| Vard. (наз.) | -as, -ias, -is, -ys | namas | kelias | medis | traukinys |
| Kilm. (род.) | -o, -io | namo | kelio | medžio | traukinio |
| Naud. (дав.) | -ui, -iui | namui | keliui | medžiui | traukiniui |
| Gal. (знах.) | -ą, -ią, -į | namą | kelią | medį | traukinį |
| Įnag. (ор.) | -u, -iu | namu | keliu | medžiu | traukiniu |
| Viet. (місц.) | -e, -yje | name | kelyje | medyje | traukinyje |
| **множина** | | | | | |
| Vard. (наз.) | -ai, -iai | namai | keliai | medžiai | traukiniai |
| Kilm. (род.) | -ų, -ių | namų | kelių | medžių | traukinių |
| Naud. (дав.) | -ams, -iams | namams | keliams | medžiams | traukiniams |
| Gal. (знах.) | -us, -ius | namus | kelius | medžius | traukinius |
| Įnag. (ор.) | -ais, -iais | namais | keliais | medžiais | traukiniais |
| Viet. (місц.) | -uose, -iuose | namuose | keliuose | medžiuose | traukiniuose |

- Місцевий відмінок однини: **-e** у слів на -as (nam**e**, miest**e**), **-yje** в інших (kel**yje**, brol**yje**).
- **t → č, d → dž** перед *-io, -iui, -iu, -iai…*: medis → me**dž**io, dviratis → dvira**č**io. Перед *-į* і *-yje* пом’якшення немає: medį, medyje. Так само, як medis, але без пом’якшення, відмінюється brolis: brolio, broliui, brolį.

## 2. Жіночий рід: -(i)a, -ė

| Відмінок | Закінчення | knyga | bažnyčia | gatvė |
|---|---|---|---|---|
| **однина** | | | | |
| Vard. (наз.) | -a, -ia, -ė | knyga | bažnyčia | gatvė |
| Kilm. (род.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Naud. (дав.) | -ai, -iai, -ei | knygai | bažnyčiai | gatvei |
| Gal. (знах.) | -ą, -ią, -ę | knygą | bažnyčią | gatvę |
| Įnag. (ор.) | -a, -ia, -e | knyga | bažnyčia | gatve |
| Viet. (місц.) | -oje, -ioje, -ėje | knygoje | bažnyčioje | gatvėje |
| **множина** | | | | |
| Vard. (наз.) | -os, -ios, -ės | knygos | bažnyčios | gatvės |
| Kilm. (род.) | -ų, -ių, -ių | knygų | bažnyčių | gatvių |
| Naud. (дав.) | -oms, -ioms, -ėms | knygoms | bažnyčioms | gatvėms |
| Gal. (знах.) | -as, -ias, -es | knygas | bažnyčias | gatves |
| Įnag. (ор.) | -omis, -iomis, -ėmis | knygomis | bažnyčiomis | gatvėmis |
| Viet. (місц.) | -ose, -iose, -ėse | knygose | bažnyčiose | gatvėse |

- Орудний відмінок однини в слів на -a збігається з називним: Einu su mam**a**.
- Родовий відмінок множини в слів на -ė — **-ių**, з пом’якшенням: kėdė → kė**dž**ių, mergaitė → mergai**č**ių.
- Кілька слів чоловічого роду відмінюються так само: **dėdė** (дядько). Прикметники при них — чоловічого роду: mano **mylimas** dėdė, du dėdes.

## 3. -is: переважно жіночий рід

| Відмінок | Закінчення | šalis | naktis | dantis (ч. р.) |
|---|---|---|---|---|
| **однина** | | | | |
| Vard. (наз.) | -is | šalis | naktis | dantis |
| Kilm. (род.) | -ies | šalies | nakties | danties |
| Naud. (дав.) | -iai; ч. р. -iui | šaliai | nakčiai | dančiui |
| Gal. (знах.) | -į | šalį | naktį | dantį |
| Įnag. (ор.) | -imi | šalimi | naktimi | dantimi |
| Viet. (місц.) | -yje | šalyje | naktyje | dantyje |
| **множина** | | | | |
| Vard. (наз.) | -ys | šalys | naktys | dantys |
| Kilm. (род.) | -ių (іноді -ų) | šalių | naktų | dantų |
| Naud. (дав.) | -ims | šalims | naktims | dantims |
| Gal. (знах.) | -is | šalis | naktis | dantis |
| Įnag. (ор.) | -imis | šalimis | naktimis | dantimis |
| Viet. (місц.) | -yse | šalyse | naktyse | dantyse |

- Знахідний відмінок множини збігається з називним однини: Aplankiau dvi naujas **šalis**.
- Давальний відмінок однини: у жіночого роду **-iai** (šaliai, širdžiai), у чоловічого **-iui** (dančiui, debesiui).
- Родовий відмінок множини зазвичай **-ių** (šalių, širdžių, akių), але в деяких слів **-ų**: naktų, ausų, žuvų, žąsų, dantų, debesų.
- Чоловічого роду небагато: dantis, debesis, žvėris; **vagis** — і чоловічого, і жіночого.

## 4. Чоловічий рід: -(i)us

| Відмінок | Закінчення | sūnus | turgus | vaisius |
|---|---|---|---|---|
| **однина** | | | | |
| Vard. (наз.) | -us, -ius | sūnus | turgus | vaisius |
| Kilm. (род.) | -aus, -iaus | sūnaus | turgaus | vaisiaus |
| Naud. (дав.) | -ui, -iui | sūnui | turgui | vaisiui |
| Gal. (знах.) | -ų, -ių | sūnų | turgų | vaisių |
| Įnag. (ор.) | -umi, -iumi | sūnumi | turgumi | vaisiumi |
| Viet. (місц.) | -uje, -iuje | sūnuje | turguje | vaisiuje |
| **множина** | | | | |
| Vard. (наз.) | -ūs, -iai | sūnūs | turgūs | vaisiai |
| Kilm. (род.) | -ų, -ių | sūnų | turgų | vaisių |
| Naud. (дав.) | -ums, -iams | sūnums | turgums | vaisiams |
| Gal. (знах.) | -us, -ius | sūnus | turgus | vaisius |
| Įnag. (ор.) | -umis, -iais | sūnumis | turgumis | vaisiais |
| Viet. (місц.) | -uose, -iuose | sūnuose | turguose | vaisiuose |

- Слова на **-ius** у множині відмінюються як *kelias*: vaisiai, vaisiams, vaisiais.
- Збігаються форми: **sūnus** — називний однини і знахідний множини (Turime du **sūnus**); **vaisių** — знахідний однини і родовий множини.
- **žmogus** — в однині як sūnus (žmogaus, žmogui, žmogumi), а в множині — **žmonės**: žmonių, žmonėms, žmones, žmonėmis, žmonėse.

| Kilm. (род.) | -ų | akmenų | šunų | seserų | dukterų |
| Naud. (дав.) | -ims | akmenims | šunims | seserims | dukterims |
| Gal. (знах.) | -is | akmenis | šunis | seseris | dukteris |
| Įnag. (ор.) | -imis | akmenimis | šunimis | seserimis | dukterimis |
| Viet. (місц.) | -yse | akmenyse | šunyse | seseryse | dukteryse |

- Закінчення додаються до основи з **-en-** (ч. р.) або **-er-** (sesuo, duktė): akmen-, vanden-, šun-, seser-, dukter- → vand**en**į, ses**er**į. Так само, як akmuo, відмінюються vanduo, ruduo, asmuo.
- **mėnuo** — виняток: основа *mėnes-* із закінченнями 1-го типу (як brolis): mėnesio, mėnesiui, mėnesį, mėnesiu, mėnesyje; множина mėnesiai, mėnesių…
